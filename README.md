# Manufacturing Knowledge Assistant

Local-first Retrieval-Augmented Generation (RAG) assistant for manufacturing documentation.

The project is built incrementally to keep the RAG pipeline explicit and testable: document ingestion, chunking, embeddings, vector retrieval, contextual generation, citations, and evaluation.

## Planned stack

- Python / FastAPI
- Sentence Transformers
- ChromaDB
- Ollama
- React
- Docker
- Pytest / GitHub Actions

## Status

🚧 V1 in progress — backend foundation and document ingestion.
